First Calculations

The examples below run one molecular and one periodic CIDER calculation. The complete PySCF and GPAW guides cover numerical choices, properties, and restarts.

Molecule with PySCF

The packaged CIDER26XC molecular model uses the normal PySCF molecular and SCF objects:

 1#!/usr/bin/env python
 2"""Closed-shell molecular CIDER26XC calculation in PySCF."""
 3
 4import argparse
 5
 6from pyscf import dft, gto
 7
 8from ciderpress.pyscf.dft import make_cider_calc
 9
10
11MODELS = ("CIDER26XCCHEM", "CIDER26XCCHEMD4", "CIDER26XCSURFSCI")
12
13
14def main():
15    parser = argparse.ArgumentParser()
16    parser.add_argument("--model", choices=MODELS, default="CIDER26XCCHEM")
17    args = parser.parse_args()
18
19    mol = gto.M(
20        atom="""
21        O  0.000000  0.000000  0.117790
22        H  0.000000  0.755453 -0.471161
23        H  0.000000 -0.755453 -0.471161
24        """,
25        basis="def2-tzvp",
26        charge=0,
27        spin=0,
28    )
29
30    base = dft.RKS(mol)
31    base.grids.level = 3
32    mf = make_cider_calc(base, args.model)
33    mf = mf.density_fit(auxbasis="def2-universal-jfit")
34    mf.conv_tol = 1e-9
35    mf.max_cycle = 200
36    energy = mf.kernel()
37
38    if not mf.converged:
39        raise RuntimeError("CIDER SCF did not converge")
40
41    print(f"model = {args.model}")
42    print(f"total energy = {energy:.12f} Ha")
43    if hasattr(mf, "e_vdw_expected"):
44        print(f"SCF/base energy = {mf.e_tot_base:.12f} Ha")
45        print(f"expected dispersion = {mf.e_vdw_expected:.12f} Ha")
46        print(f"dispersion adjustment = {mf.e_vdw_delta:.12f} Ha")
47
48
49if __name__ == "__main__":
50    main()

Run it from the repository root with:

python examples/pyscf/production_calc.py --model CIDER26XCCHEM

The example raises RuntimeError when the SCF does not converge. It prints the base, expected dispersion, and adjustment terms for every CIDER26XC model. With CIDER26XCCHEMD4 they show how the final total was assembled; CIDER26XCCHEM and CIDER26XCSURFSCI print zero for the dispersion entries.

Exchange-only model with PySCF

Packaged CIDER23X and CIDER24X are exchange functionals. The following example supplies the PBE0/CIDER surrogate composition:

 1#!/usr/bin/env python
 2"""Run a packaged CIDER23X or CIDER24X exchange model with PySCF."""
 3
 4import argparse
 5
 6from pyscf import dft, gto
 7
 8from ciderpress.dft.model_utils import CIDER23X_MODELS, CIDER24X_MODELS
 9from ciderpress.pyscf.dft import make_cider_calc
10
11
12MODELS = CIDER23X_MODELS + CIDER24X_MODELS
13
14
15def main():
16    parser = argparse.ArgumentParser()
17    parser.add_argument("--model", choices=MODELS, default="CIDER23X_NL_MGGA_DTR")
18    args = parser.parse_args()
19
20    mol = gto.M(
21        atom="H 0 0 0; H 0 0 0.74",
22        basis="def2-svp",
23        charge=0,
24        spin=0,
25    )
26
27    base = dft.RKS(mol)
28    base.grids.level = 3
29    mf = make_cider_calc(
30        base,
31        args.model,
32        xmix=0.25,
33        xkernel="GGA_X_PBE",
34        ckernel="GGA_C_PBE",
35    )
36    mf = mf.density_fit(auxbasis="def2-universal-jfit")
37    mf.conv_tol = 1e-9
38    mf.max_cycle = 200
39    energy = mf.kernel()
40
41    if not mf.converged:
42        raise RuntimeError("CIDER SCF did not converge")
43    print(f"model = {args.model}")
44    print(f"total energy = {energy:.12f} Ha")
45
46
47if __name__ == "__main__":
48    main()

The explicit xmix, xkernel, and ckernel arguments define the surrogate-hybrid composition. For CIDER24X, install ciderpress[cider24] and select the corresponding name.

Periodic solid with GPAW

The periodic example first writes a full PBE checkpoint and then restarts it with CIDER26XCSURFSCI:

 1#!/usr/bin/env python
 2"""PBE-seeded periodic CIDER26XCSURFSCI calculation in classic GPAW."""
 3
 4from ase.build import bulk
 5from ase.parallel import parprint
 6from gpaw import GPAW, Mixer, PW
 7
 8from ciderpress.gpaw.calculator import CiderGPAW, get_cider_functional
 9
10
11def main():
12    atoms = bulk("Si")
13    atoms.calc = GPAW(
14        xc="PBE",
15        mode=PW(400),
16        kpts={"size": (4, 4, 4), "gamma": False},
17        occupations={"name": "fermi-dirac", "width": 0.1},
18        mixer=Mixer(0.05, 5, 50),
19        convergence={"energy": 1e-5, "density": 1e-5,
20                     "eigenstates": 1e-3, "bands": "occupied"},
21        parallel={"augment_grids": True},
22        txt="si_pbe.txt",
23    )
24    atoms.get_potential_energy()
25    # The production models are meta-GGAs and need the wavefunctions to
26    # reconstruct the kinetic-energy density after restart.
27    atoms.calc.write("si_pbe.gpw", mode="all")
28
29    xc = get_cider_functional(
30        "CIDER26XCSURFSCI",
31        xmix=1.0,
32        xkernel=None,
33        ckernel=None,
34        pasdw_store_funcs=False,
35    )
36    calc = CiderGPAW(
37        restart="si_pbe.gpw",
38        xc=xc,
39        mixer=Mixer(0.05, 5, 50),
40        occupations={"name": "fermi-dirac", "width": 0.1},
41        maxiter=500,
42        parallel={"augment_grids": True},
43        txt="si_cider.txt",
44    )
45    atoms = calc.get_atoms()
46    atoms.calc = calc
47    energy = atoms.get_potential_energy()
48    calc.write("si_cider.gpw", mode="all")
49    parprint(f"CIDER26XCSURFSCI energy = {energy:.12f} eV")
50
51
52if __name__ == "__main__":
53    main()

Run GPAW examples with the MPI launcher and rank count appropriate for the installed GPAW build, for example:

mpirun -np 4 python examples/gpaw/production_calc.py
